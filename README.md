# Frame Perfect — emulador

O código-fonte do emulador usado pelo Frame Perfect: o
[FinalBurn Neo](https://github.com/finalburnneo/FBNeo) com as modificações do
Frame Perfect, publicado conforme a licença do FBNeo (`LICENSE-FBNEO.txt`).

| | |
|---|---|
| `FBNEO_PIN.txt` | a versão do FBNeo usada como base |
| `fbneo.diff` | as mudanças feitas no FBNeo |
| `rollback_netcode/` | o código que o emulador inclui; a libggpo (licença MIT) em `third_party/ggpo` |
| `compilar.sh` | como compilar (Windows, MSYS2 MINGW64) |

Não há ROMs aqui.
